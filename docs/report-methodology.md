# 美股 10 分鐘熱點雷達｜報告方法

此雷達只做市場觀察與研究，不預測報酬、不提供交易建議、不執行交易。

- 以 XNYS 交易日曆和不可變掃描快照定義 ET 交易日、時窗與市場狀態。觀察時間與發布記錄時間分開標示。
- 指數、板塊與主題代理以完整的一分鐘成交 K 線計算窗口價格、量能、相對表現和聚類；不以全天變化冒充短窗證據。
- 缺資料、零成交、陳舊報價、來源失效會降低覆蓋可信度；資料不足不等於市場平靜。
- 只對已確認價格異常研究催化劑。來源須確認內容及實際發布時間；同時發生不證明因果，未確認須明示。
- 熱點分數是注意力排序啟發式，不是預測。樣本廣度、代理資產與來源延遲須明確限定。
- 每輪可見摘要僅列重要方向、關鍵證據、代表廣度、催化劑信心與重要反證；完整資料、來源時間、錯誤及缺口置於該輪明細折疊區。
